Practical 17 — Blood Donation
Eligibility Checker

Scenario
A blood donation camp is being organized by a hospital. Before allowing a volunteer
to donate blood, the medical staff checks whether the donor satisfies the eligibility
criteria. To reduce manual verification, the hospital wants a simple application that
automatically determines whether a person is eligible to donate blood.
Develop this application using C.
Problem Statement
Write a C program that accepts the following details:
• Donor Name
• Age
• Weight (kg)
• Hemoglobin Level (g/dL)
A person is eligible to donate blood only if:
• Age is between 18 and 60 years
• Weight is at least 50 kg
• Hemoglobin level is at least 12.5 g/dL

If all conditions are satisfied, display “Eligible for Blood Donation”. Otherwise, dis-
play “Not Eligible for Blood Donation.”

Functional Requirements
The program should:
• Accept donor details.
• Verify all eligibility conditions.
• Display eligibility status.
• Display an appropriate message for the user.
